기초서류 연결

공시실에서 내려받은 사업방법서·상품요약서·약관 PDF 폴더를 연결합니다. 문서는 내 PC 안에서만 읽고, 외부로는 아무것도 보내지 않습니다.

현재 연결 상태

폴더—
상태연결된 폴더 없음 — start.bat으로 실행하면 지정 폴더가 자동 연결됩니다
불러온 문서—

사업방법서·약관·상품요약서 폴더를 선택하면 브라우저가 PC 안에서 본문을 읽어 검색에 포함합니다. 파일은 어디에도 업로드·저장되지 않으며, 창을 닫으면 사라집니다.

연결 방법

  1. start.bat 더블클릭 — 처음 한 번 PDF 폴더 경로를 물어보고, 다음부터는 그 폴더를 자동으로 연결합니다.
  2. change-folder.bat — 다른 폴더로 바꿀 때. 폴더별 색인은 따로 보관되어 예전 폴더로 돌아가도 다시 읽지 않습니다.
  3. 새로고침 — 폴더에 PDF를 추가·수정한 뒤 누르면 바뀐 파일만 다시 읽습니다.
  4. 폴더 선택 — index.html을 더블클릭해 연 경우에만 사용(창을 닫으면 다시 선택).

공시실 서류를 아직 받지 않았다면 아래 공시실 서류 내려받기를 먼저 따라 합니다.

폴더 구성 예

기초서류폴더
├─ 판매중                        ← 판매여부 폴더 (판매중 · 판매상품)
│   └─ 2026 / 2026.04.01         ← 판매개시일 (폴더명)
│       └─ (무)OO연금저축보험 / [보험약관] … .pdf
└─ 판매중지                      ← (판매중지 · 판매종료 · 판매중지상품)
    └─ 2014 / 2014.02.03 / (무)OO연금보험 / … .pdf

판매상태는 판매중/판매중지 폴더를 기준으로 합니다. 판매중 폴더 상품도 같은 상품의 더 최근 판매일자가 있으면 이전 판매일자는 판매종료로 봅니다. 판매여부 폴더가 없으면 판매일자로 추정하고 상품 목록에 '추정'으로 표시합니다.

파일명에 상품명과 문서유형(사업방법서·상품요약서·약관)이 들어 있으면 상품별로 자동으로 묶입니다(파일명에 상품명이 없으면 상품명 폴더 이름). "계약자용"은 같은 상품으로 봅니다.

공시실 서류 내려받기 하나생명 공시실 · 전체상품 목록

공시실의 전체상품 목록(판매상품 · 판매중지상품)에서 상품요약서·사업방법서·보험약관을 한 번에 내려받는 별도 도구입니다. 내 PC에서 실제 브라우저로 목록 화면의 [다운로드] 버튼을 차례로 눌러 받고, 이 앱이 바로 읽을 수 있는 폴더 구조로 정리합니다.

  1. STEP 1

    다운로드 도구 받기

    크롬에서 아래 주소로 ZIP을 받아 압축을 풀고, 안의 261013\hanalife_docs 폴더를 엽니다.

    https://github.com/lwhdngus-design/261014/archive/refs/heads/claude/hanalife-product-docs-download-089p7m.zip
    파일설명
    run_download.bat더블클릭 실행 — 패키지 설치 → 브라우저 준비 → 다운로드를 한 번에
    hanalife_download.py다운로드 프로그램 (Python · Playwright)
    requirements.txt필요한 패키지(playwright)
  2. STEP 2

    실행

    run_download.bat 더블클릭, 또는 폴더 주소창에 cmd 입력 → Enter 후 아래를 차례로 입력합니다. 먼저 --limit 3으로 시험해 보고 전체를 받습니다.

    python -m pip install -r requirements.txt
python hanalife_download.py --limit 3      ← 시험 (페이지당 3개 상품)
python hanalife_download.py                ← 판매 + 판매중지 전체
    옵션설명
    --status on / off판매상품만 / 판매중지상품만
    --out "폴더 경로"저장 위치 지정 (교육장 등 다른 PC는 사용자 폴더 이름이 다르므로 지정 권장)
    --headed브라우저 창을 보면서 실행
    --chrome "실행파일 경로"크롬·엣지를 자동으로 못 찾을 때 직접 지정 (설치된 크롬 → 엣지 순으로 자동 탐색)

    python이 안 되면 py로 바꿔 입력합니다. 회사망에서 브라우저 설치(playwright install)가 막혀도 설치된 크롬·엣지로 실행됩니다.

  3. STEP 3

    결과 확인

    화면에 서류마다 OK / NG가 표시되고, 끝나면 성공·건너뜀·실패·서류없음 건수가 나옵니다. 같은 상품도 판매기간별로 따로 저장합니다.

    상품기초서류폴더
├─ 판매중                            ← 판매상품 목록
│   └─ 2026 / 2026.04.01             ← 판매시작 연도 / 판매시작일
│       └─ (무)OO연금저축보험          ← 상품명
│           ├─ [상품요약서] 원본파일명.pdf
│           ├─ [사업방법서] 원본파일명.pdf
│           └─ [보험약관] 원본파일명.pdf
├─ 판매중지                          ← 판매중지상품 목록
│   └─ 2014 / 2014.02.03 / (무)OO연금보험 / …
└─ download_log.csv                 ← 서류별 결과(성공/이동/실패/서류없음)와 저장 경로

    다시 실행하면 이미 받은 파일은 건너뛰고 새 서류와 실패한 것만 받습니다(중간에 끊겨도 이어받기). 판매중이던 상품이 판매중지로 바뀌면 다시 받지 않고 판매중지 폴더로 옮기기만 합니다(화면 MV, 로그 "이동"). download_log.csv는 지우지 마세요. 공시실 화면 구조가 바뀌면 "상품 표를 찾지 못했습니다"가 나올 수 있습니다.

  4. STEP 4

    이 앱에 연결

    change-folder.bat 실행 → 위 저장 폴더(상품기초서류폴더, 판매중·판매중지 폴더의 위) 경로를 붙여넣으면 자동으로 색인하고 엽니다. 이후 서류를 더 받았으면 이 화면의 새로고침으로 새 파일만 읽습니다.

    판매일자는 날짜 폴더(2026.04.01)에서, 상품명은 파일명(없으면 상품명 폴더)에서, 문서유형은 [사업방법서]·[상품요약서]·[보험약관] 머리표에서 읽습니다. 공시실 공개 문서만 사용하고, 받은 PDF는 내 PC에만 둡니다.

교육용 실습

실제 회사 자료 없이, 가상 보험사 '가나다생명'의 기초서류 PDF와 상품 DB로 앱의 모든 기능을 따라 해 볼 수 있습니다. 모든 자료는 교육용으로 만든 가상 데이터입니다.

  1. STEP 1

    앱 받기

    Git으로 받거나, 깃허브 화면에서 브랜치를 고른 뒤 Code → Download ZIP으로 받아 압축을 풉니다. 이미 받았다면 update.bat으로 최신 버전을 받습니다.

    git clone -b claude/excel-2an-sheet-format-svwm4c https://github.com/lwhdngus-design/261007.git

    필요한 프로그램: Python 3 (추가 설치 패키지 없음), Chrome 권장

  2. STEP 2

    교육용 자료 내려받기

    자료내용내려받기
    가상 기초서류 PDF가나다생명 5개 상품 · 판매일자별 사업방법서·상품요약서·약관
    가상 상품 DB상품 목록 (상품코드·판매기간·개정차수·예정이율 등)
    보장 내역 (지급사유·지급률·감액·면책기간)
    상품위원회 등 심의 문서
    월별 보유계약 현황
    특징 사전질문 검색·특징 판정 규칙 (한 줄 = 특징 하나)

    같은 자료가 앱 폴더 안 sample-기초서류폴더, dummy-data에도 들어 있습니다. CSV는 엑셀에서 바로 열립니다.

  3. STEP 3

    샘플로 실행

    start-sample.bat 더블클릭 → 가상 기초서류로 앱이 열립니다. 내 기초서류 폴더 설정은 바뀌지 않으며, 회사 문서로 돌아갈 때는 start.bat으로 실행합니다.

  4. STEP 4

    따라 해 보기

    누르면 기초서류 검색 화면에서 바로 실행됩니다.

    실행 결과 바로 보기

    누르면 해당 실행 결과 화면이 바로 열립니다. 주소 끝에 붙는 이름(예: #analysis)으로 링크를 걸 수 있습니다.
